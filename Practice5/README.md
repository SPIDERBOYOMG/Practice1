# Practice5 - Receipt Parser

A Python script that parses raw receipt text and outputs structured JSON data.

## Files

- `receipt_parser.py` — Main script that reads and parses receipt data
- `raw.txt` — Raw receipt input text
- `output.json` — Parsed output in JSON format

## Usage

```bash
python receipt_parser.py
```

The script reads from `raw.txt` and writes structured data to `output.json`.

## Output Format

The parsed receipt data is saved as JSON, making it easy to process programmatically.
