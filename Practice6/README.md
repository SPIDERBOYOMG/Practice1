# Practice6 Repository

This repository contains Python practice scripts organized into three categories:

## 📂 Structure
- **file_handling/** → Reading, writing, copying, and deleting files
- **directory_management/** → Creating, listing, and moving directories/files
- **builtin_functions/** → Examples of Python built-in functions (`map`, `filter`, `reduce`, `enumerate`, `zip`)

## 🚀 How to Run
Navigate into each folder and run the scripts:
```bash
python file_handling/read_files.py
python builtin_functions/map_filter_reduce.py
